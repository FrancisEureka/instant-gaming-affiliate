## ⚙️ Configuração de Secrets (WhatsApp)
Para ativar o disparo no WhatsApp, adicione em **Settings > Secrets and variables > Actions**:
- WHATSAPP_API_URL: URL da sua API (Evolution API / Z-API)
- WHATSAPP_API_KEY: Chave da API
